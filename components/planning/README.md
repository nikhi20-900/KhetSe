# Planning & Feasibility Components

## Component Scope

This directory contains user interface components for evaluating and comparing logistics options:

- `PlanComparisonCard.tsx`: Multi-dimensional card rendering transit duration, cost, and expected proceeds.
- `CostBreakdownTable.tsx`: Itemized breakdown of transport charges, handling fees, and storage costs.
- `ConstraintRejectionBadge.tsx`: Visual badge indicating violated constraints with explicit explanations.
- `PlanSelector.tsx`: Interactive selection mechanism transitioning chosen plan to reservation booking.
