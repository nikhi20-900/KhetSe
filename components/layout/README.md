# Layout Components

## Component Scope

This directory contains application shell and navigational layout components:

- `Header.tsx`: Top navigation bar with branding, environment indicators, and primary navigation links.
- `Sidebar.tsx`: Contextual navigation for harvest and shipment management.
- `Footer.tsx`: Application footer containing system disclosures and simulated data status notices.
- `Breadcrumbs.tsx`: Hierarchy indicators for multi-step workflow navigation.
